# SussIt

Know before you buy.

Australian mobile-first second-hand buying decision app. Upload a Marketplace listing screenshot — SussIt identifies the product, compares current asking prices, and helps you decide what to offer.

## Stack

React · TypeScript · Vite · Tailwind · shadcn-style UI

## Develop

```bash
npm install
npm run dev
```

## V0 scope

Mock UI only for now (Meta Quest 3 512GB demo flow):

- `/` Home
- `/confirm` Product confirmation
- `/analysing` Progress
- `/result/:id` Evidence + suggested offer

No auth, Stripe, eBay, or OpenAI wired yet.
