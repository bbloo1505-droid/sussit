# SussIt strategy (locked Jul 2026)

## North star

**Before I buy anything off Marketplace, I SussIt.**

Not: “Cool AI app that estimates prices.”

## Product wedge

- **Intake:** user-supplied listing (screenshot / paste). Later: Chrome “Suss this listing.”
- **Intelligence:** eBay asking comps + SussIt matcher / product graph / (later) velocity.
- **Verdicts:** strong Buy/Offer only where data is good (phones → gaming → VR first).

Marketplace is the sourcing surface. **SussIt is the intelligence layer.**

## Explicit non-goals (now)

- No Pro paywall yet — we don’t know if limits would hurt.
- No inventory management / seller CRM.
- No “scan absolutely anything” obsession.
- No automated Facebook Marketplace scraping.
- No elaborate subscription architecture.
- No Hunter/alerts until users ask: “why can’t SussIt find these for me?”

## Milestone order

1. **Accuracy + real-user testing**  
   Phones → gaming → VR. Bad comps must be rare. Trust Max Buy / offer.
2. **Product normalisation + lifecycle dataset**  
   Observations on specific models/variants — long-term moat.
3. **Chrome extension**  
   Only once analysis is trustworthy (legal review vs Meta automated-collection rules).
4. **Pro paywall**  
   Only after users repeatedly hit a natural usage pain.
5. **Hunter**  
   Only after demand for opportunity discovery is proven.

## Near-term user proof (before monetisation)

Recruit ~**20–50 active flippers** on real Marketplace listings.

Track ground truth:

```
Listing analysed
→ SussIt verdict
→ Contacted seller?
→ Bought?
→ Purchase price
→ Resold?
→ Resale price
→ Time to resale
→ Was SussIt correct?
```

## Obsess over

**% of SussIt recommendations users later say were correct** — not registrations, scans, or paid users yet.

## Monetisation (later — not next)

| Tier | Role |
|------|------|
| Free | Useful: value, comps, verdict, offer |
| Pro ~A$12.99/mo | Power flippers — after usage proves demand |
| Hunter ~A$25–30/mo | Only after “find deals for me” demand |

Avoid weekly mobile pricing traps.

## Competitor context

- ThriftAI owns thrift-store photo scanning.
- Marketplace deal intelligence is still open.
- Do not copy scraper-dependent businesses as the core moat.
